## Назначение файлов

| Файл | Назначение |
|---|---|
| `make_test_data.py` | создаёт тестовые данные в папке `company_data/` (2 отдела по 7 CSV-файлов) |
| `backup.py` | резервное копирование: архив `tar.gz` + JSON-манифест с SHA-256, ротация (хранится 5 копий), проверка восстановления с отчётом о различиях, восстановление после инцидента |
| `rpo_rto.md` | расчёт RPO и RTO для университета (задание 5) |

Папки `company_data/`, `backups/` в репозиторий не добавляются (см. `.gitignore`).

## Команды запуска

```
python make_test_data.py       # создать тестовые данные
python backup.py               # создать копию, удалить старые, проверить восстановление
python backup.py verify        # проверить последнюю копию (подробный отчёт о различиях)
python backup.py restore       # восстановить company_data из последней копии
```
